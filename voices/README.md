# The voice

Breeze TTS 2 clones the voice in a clip you put here. No clip comes with the repo: use one
you have the right to use.

- `soldier.wav`: the clip, 5 to 20 seconds of clean speech (mono WAV). (The name is Kevin's,
  from the example; any name works, see below.)
- `soldier.txt`: exactly what's said in it.

Set `voice_reference` in `m8.toml` to use another clip (its transcript is the `.txt` of the
same name beside it).
