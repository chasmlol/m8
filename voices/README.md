# Kevin's voice

Breeze TTS 2 clones the voice in a clip you put here. No clip comes with the repo: use one
you have the right to use.

- `soldier.wav`: the clip, 5 to 20 seconds of clean speech (mono WAV).
- `soldier.txt`: exactly what's said in it.

Another name works too: set `voice_reference` in `mate.toml` (the transcript is the `.txt` of
the same name beside it).
